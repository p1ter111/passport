# Passport Atlas

Passport Atlas is a global passport and visa exploration platform built with Next.js, React, and TypeScript.

## Features

- Interactive 2D and 3D world maps
- Passport rankings and country profiles
- Visa-free, visa-on-arrival, e-visa, ETA, and visa-required data
- Side-by-side passport comparison
- Route-based trip and visa planning
- Passport cover and edition history collection
- Internationalized interface

## Development

```bash
npm install
npm run dev -- --port 3001
```

Open `http://127.0.0.1:3001/`.

## Verification

```bash
npm run lint
npm run history:validate
npm run build
```

Visa and entry requirements can change at any time. Always verify the latest rules with the destination's official immigration authority or embassy before travel.
